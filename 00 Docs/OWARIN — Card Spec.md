# OWARIN — Card Spec

ไฟล์อ้างอิงเดียวของงานการ์ดโฆษณา แก้ที่นี่ก่อนแก้โค้ดทุกครั้ง
เครื่องมือ: `owarin_arrival_card_studio.html`
ต้องมีไฟล์คู่: `owarin_covers.js` (ปกตัวอย่าง) · `owarin_logo.js` (ตราดอกไม้)
ทดสอบ: `node owarin_card_test.mjs` — **ต้องผ่าน 100% ก่อนส่งงานทุกครั้ง**

**Reference:** RINKAN銀座silver店 — Instagram/Facebook Stories 2 แบบ (NEW ARRIVAL grid, 中古特別価格 sale list)

## กฎเหล็ก 13 ข้อ

ทุกข้อมาจากการเทียบกับ RINKAN ตรงๆ ห้ามละเมิดโดยไม่คุยก่อน

1. **หนึ่งช่อง = ข้อความหนึ่งชิ้น** — GRID ขึ้นแค่ราคา ไม่มีชื่อสินค้า (ปกหนังสือมีชื่อเกมตัวใหญ่อยู่แล้ว ใส่ซ้ำคือขยะ)
2. **ขนาดตัวอักษรตายตัว** — ห้ามย่อรายช่อง ราคาทุกช่องขนาดเดียวกันเป๊ะ
3. **พาดหัว 2 บรรทัด** — ขนาดเดียวกันทั้งสองบรรทัด ย่อลงมาให้พอดี ห้ามตกบรรทัดที่ 3
4. **การ์ดขาวสนิทบนพื้นเทาอ่อน** — ความคมของขอบการ์ดคือสิ่งที่ทำให้ดูแพง ห้ามทำเทาบนเทา
5. **contain-fit เสมอ ห้ามครอปรูป** — ที่ว่างรอบเล่มในรูปคืออากาศที่ต้องการ
6. **ไม่เพิ่มอะไรเกินจำเป็น** — ของเสริมทุกอย่างปิดเป็นค่าเริ่มต้น
7. **ห้ามส่งงานโดยไม่รัน `node owarin_card_test.mjs` ให้ผ่าน 100% ก่อน**
   การอ่านโค้ดหรือตรวจด้วย regex ไม่นับ ต้องรันโค้ดจริง
8. **ห้ามใช้ string replace แบบเหมารวมกับโครงสร้างข้อมูล** — ให้ระบุ key ให้ชัด
   (บั๊ก v16 เกิดจาก replace `'4:5' :{` แล้วไปโดนทั้ง `PRESET` และ `SAFE`)
9. **ห้ามฮาร์ดโค้ดข้อความ สี หรือขนาด ที่วาดลงการ์ด** — ทุกตัวต้องมีตัวควบคุมใน UI
   เพิ่มฟีเจอร์ใหม่ต้องเดินสายให้ครบทั้งเส้น: `P` → UI → `PRESET` ทั้ง 5 ชุด → บันทึกค่า → เทสต์
10. **ทุกขนาดต้องเป็นค่าอิสระ = % ของความกว้างภาพ ห้ามผูกกับขนาดตัวอื่น**
   ปรับตัวไหนต้องมีผลเฉพาะตัวนั้น · เดิมบรรทัดญี่ปุ่นและตราดอกไม้ผูกกับขนาดชื่อร้าน
   ทำให้ขยับชื่อร้านแล้วทุกอย่างขยับตาม ควบคุมสัดส่วนไม่ได้
11. **เปลี่ยนความหมายของค่า = ต้องขึ้นเวอร์ชันคีย์ localStorage และแก้ค่าเริ่มต้นให้ครบทั้ง `P` และ `PRESET` ทั้ง 5 ชุด**
   ค่าเก่าที่ค้างอยู่จะถูกตีความด้วยสูตรใหม่ทันที (บั๊ก v19: `markSize` 150 → 1620px วาดหลุดเฟรม โลโก้จึงหาย)
   `load()` บีบทุกค่าเข้าช่วงสไลเดอร์เสมอเป็นเกราะชั้นสอง
12. **แก้โค้ดด้วย string replace ต้องยืนยันว่าแทนที่สำเร็จทุกจุด** — `assert` ว่าเจอข้อความเป้าหมาย
   แล้วตรวจซ้ำว่าไม่เหลือรูปแบบเดิม (บั๊ก v20: แก้ `f*P.x` → `W*P.x` ไม่สำเร็จแต่ผมไม่ได้ตรวจ)
13. **"ถูกวาด" ไม่เท่ากับ "มองเห็น"** — เทสต์ต้องเช็คขนาดจริงด้วย
   ตัวอักษรต้อง ≥ 0.8% ของความกว้าง · รูปต้อง ≥ 2% (บั๊ก v20: ญี่ปุ่น 0.48px ตรา 2.7px ถูกวาดแต่มองไม่เห็น)

## ขนาดไฟล์ &amp; safe zone

### ข้อเท็จจริงสำคัญ: ไม่มีสเปคทางการชุดเดียว

Meta **ไม่ได้ประกาศตาราง safe zone อย่างเป็นทางการชุดเดียว** แหล่งอ้างอิงที่น่าเชื่อถือให้ตัวเลขต่างกันชัดเจน

| แหล่ง | Stories | Reels |
|---|---|---|
| Lucid Media · Billo · behaviour.digital | บน 270px · ล่าง 380px · ข้าง 65px | บน 270px · **ล่าง 670px** · ข้าง 65px |
| First Pier · Outfy · Minta | บน 250px · ล่าง 250px · ข้าง 65px → safe 950×1420 | บน 108px · ล่าง 320px · ซ้าย 60 ขวา 120 → safe 900×1492 |

ต่างกันถึง **350px** ที่ขอบล่างของ Reels — เยอะเกินกว่าจะเป็นความคลาดเคลื่อนเล็กน้อย

**ตัวชี้ขาดคือ Safe Zone Guardrail ในหน้าพรีวิวของ Ads Manager** ไม่ใช่บล็อกใดบล็อกหนึ่ง
เครื่องมือจึงทำเป็นโปรไฟล์ให้เลือก 3 แบบ แล้วไปยืนยันกับของจริง

**เนื้อหาทุกชิ้นอยู่ในกรอบเสมอทุกสัดส่วน** (ตั้งแต่ v14) — พาดหัว การ์ด และโลโก้อิงกรอบ safe zone

พร้อมเส้นประเทียบโปรไฟล์อื่น

## GRID — ของเข้าใหม่

โครง: พาดหัว (บนพื้น) → การ์ดขาว + ตาราง → โลโก้ (บนพื้น มุมล่างขวา)

| องค์ประกอบ | ค่า (อิง W = ความกว้างภาพ) |
|---|---|
| ขอบซ้าย-ขวา M | `W*0.055` |
| พาดหัว กว้างสูงสุด | `W*0.55` |
| พาดหัว ขนาด | ย่อจาก `W*0.098` ลงถึง `W*0.036` |
| ระยะบรรทัดพาดหัว | `hp*0.96` |
| วันที่ | `W*0.022` สีรอง |
| ระยะในการ์ด pad | `W*0.040` |
| ช่อง (cols) | 3 · แถว 2 (6 ช่อง) หรือ 3 (9 ช่อง) |
| โซนข้อความในช่อง | `min(gh*0.17, W*0.052)` |
| กรอบรูป | contain ใน `gw*0.86 × imgArea*0.92` |
| **ราคา** | **`W*0.024` ตายตัว น้ำหนัก 400 จัดกลาง** |
| เส้นคั่นแถว | กว้าง `gw*0.86` จัดกลาง สีเส้นคั่น |
| โลโก้ | Archivo 700 `W*0.034` มุมล่างขวา |

**6 หรือ 9 ช่อง** — เลือกได้ 6 ช่องปกกว้าง ~233px อ่านชื่อเกมบนปกออก · 9 ช่องปกกว้าง ~163px โชว์ของได้มากกว่าแต่ปกเล็กลง

## ชุดรูปที่ต้องเตรียม

Watermark Studio → พื้นหลัง `#FFFFFF` → **ปิดลายน้ำ** → export เก็บแยกเป็นชุดสำหรับโฆษณา

เหตุผล: การ์ดขาว + พื้นหลังรูปขาว = ขอบรูปหายสนิท และที่ว่างรอบเล่มกลายเป็นอากาศแบบ RINKAN
ลายน้ำไม่ต้องมี เพราะมีโลโก้บนการ์ดแล้ว (RINKAN ไม่มีลายน้ำบนรูปสินค้าสักใบ)

## พารามิเตอร์ที่ปรับได้ (สไลเดอร์)

ค่าเริ่มต้นมาจาก **พรีเซ็ตตามขนาด** (5 ชุด) สลับขนาดแล้วปรับให้เองถ้าเปิด Auto-tune
ทุกตัวปรับต่อได้เองและจำค่าไว้ใน localStorage

ทั้งหมด 41 ตัว **ทุกตัวเป็น % ของความกว้างภาพและอิสระต่อกัน** ยกเว้นที่ระบุ ยกเว้น Header/Footer band height ที่เป็น % ของ **ความสูง**
และ offset ทั้งสองตัวที่เป็นสัดส่วนของที่ว่างในแถบ (−50…50)

| | **Weight · Letter spacing** | 600–900 · −0.6…1.6% |
| | Subtitle size · Subtitle gap | 1.2–4% · 0–6% |
| | Header band height · Header vertical position | 6–34%H · −50…50 |
| 5 · GRID | Name size · Price size | 0.8–3.5% · 1.4–4.5% |
| | Gap below cover · Text zone height | 0–6% · 10–34% |
| | **Price prefix · suffix · SOLD text · SOLD size** | ช่องกรอก · 1–6% |
| 6 · FOOTER | **Store name text · Japanese line text** | ช่องกรอก |
| | Store name size · **weight · letter spacing** | 1.8–6% · 400–900 · −0.6…1.6% |

| | Logo mark size · Logo mark gap | 0–14% · 0–6% |

| | **ป้าย SALE** ราคาปกติ / ราคาพิเศษ / ราคา · คำนำหน้าหมายเหตุ | ช่องกรอก |

รวม 30 ตัว + ช่องข้อความ 20 ช่อง · ค่าเริ่มต้นมาจากพรีเซ็ตตามขนาด 5 ชุด

**ปรับรายช่อง** — ลากบนพรีวิวขึ้น-ลงเพื่อเลื่อนรูป · Shift+ลาก = ซูม · ดับเบิลคลิก = คืนค่า
สโคป `ช่องนี้ / ทุกช่อง` · ซูมพรีเซ็ต 3 ช่อง (P1/P2/P3) · แถบ Bulk ด้านบนพรีวิว

ตรวจแล้ว 72 เคส (3 สัดส่วน × 2 จำนวนช่อง × 6 สไลเดอร์ × สุดขอบทั้งสองด้าน) ไม่มีค่าไหนทำให้เลย์เอาต์พัง

## กฎการตัดชื่อไฟล์ → ชื่อเกม

ใช้ทั้งตอนค้นหาและตอนเติมชื่อลงช่อง

| ตัดอะไร | ตัวอย่าง |
|---|---|
| `(RESTOCK-xx)` รวมที่สะกดผิด `RESOTCK` | `Metal Gear Solid (RESTOCK-01)` → `Metal Gear Solid` |
| `(1)` `(2)` ท้ายชื่อ (รูปหน้า-หลัง) | `Alone in the Dark (2)` → `Alone in the Dark` |
| จุดคั่น `・` และวงเล็บว่างที่ค้างหลังตัด | `(Incl. Sphere Map・RESTOCK-02)` → `(Incl. Sphere Map)` |
| นามสกุลไฟล์ | |

**เก็บไว้:** `(Incl. Map)` `(สีทั้งเล่ม)` `(DAMAGED)` และวงเล็บอื่นที่บอกรายละเอียดสินค้าจริง

**การจับคู่** normalize เพิ่ม `include` → `incl` แล้วตัดอักขระที่ไม่ใช่ a-z0-9
วัดผลกับข้อมูลจริง: จับคู่ CSV 364 รายการกับไฟล์รูป 2,573 ไฟล์ได้ **352 รายการ (97%)**
ที่เหลือ 12 รายการคือของที่ไม่มีรูปในโฟลเดอร์นั้น
