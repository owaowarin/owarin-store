### 3.1 ทำไมต้องมี `gallery.json` — ใช้สูตรเดา URL ไม่ได้

| วิธี | ปัญหา |
|---|---|
| เดาจาก Product ID เหมือน `catalog/` | ได้แค่ **รูปเดียว** — ไม่รู้ว่าเล่มนี้มี 1 ใบหรือ 6 ใบ |
| ชี้ไปที่ `library/` ตรง ๆ | path มีเว้นวรรค · `｜` · `⨯` · `・` · ภาษาไทย → ต้อง encode ทุกส่วน และ**ยังไม่รู้จำนวนรูปอยู่ดี** |
| **manifest JSON** ✅ | รู้จำนวน · รู้ชื่อไฟล์เดิม (ไว้ตั้งชื่อตอนดาวน์โหลด) · เปลี่ยนโครง R2 ทีหลังได้โดยไม่แตะ Index.html |

### 3.2 ทำไมสร้าง `gallery/` ใหม่ ไม่ใช้ `library/` เดิม

| | `library/` เดิม | `gallery/` ใหม่ (แนะนำ) |
|---|---|---|
| URL | ต้อง encode 3 ชั้น เสี่ยงพังในแชท | ASCII ล้วน `gallery/OWA-GGBF027YKAR01/01.jpg` |
| ขอบเขต | ทุกสถานะ 1,653 รูป | เฉพาะ Instock ~780 รูป |
| ขนาด | 306 MB | **~120 MB** (+ thumb 7 MB) |
| ลบตอนขายออก | ต้องไล่หา path เดิม | `rclone purge gallery/<PID>` จบ |
| ชื่อไฟล์ตอนโหลด | ชื่อเดิม | เก็บชื่อเดิมไว้ใน manifest → zip ได้ชื่อเดิม |

รวมใช้ R2 หลังทำเสร็จ ≈ **500 MB จากโควตาฟรี 10 GB (5%)** — `library/` เดิมยังอยู่ครบ ไม่ต้องลบ

## 5. รายละเอียดแต่ละเฟส

### I1 — `image_match.py` (ไฟล์ใหม่ ไม่ทับ `prepare_r2_upload.py`)

**เปลี่ยนจากของเดิม 4 จุด**

1. `SOURCE_DIRS` = list 5 โฟลเดอร์ แทนตัวแปรเดี่ยว
2. ไฟล์ลอยที่ root ของโฟลเดอร์ → ตัด ` (N)` ออกก่อนใช้เป็นชื่อ item
3. **จับคู่ 3 ชั้น** ตามลำดับ หยุดที่ชั้นแรกที่เจอ:
   - ชั้น A — ชื่อตรงเป๊ะ (หลัง normalize ช่องว่าง + casefold)
   - ชั้น B — ตัด `(RESTOCK-xx)` / `・RESTOCK-xx` แล้วเทียบชื่อฐาน
   - ชั้น C — ตาราง override ที่กรอกเอง `image_overrides.csv` (`Product ID, folder path`)
     → **ทางออกสุดท้ายที่แก้ได้เองโดยไม่ต้องแตะโค้ด** เจอเคสแปลกเมื่อไหร่กรอกบรรทัดเดียวจบ
4. `READY_STATUS = {"instock"}` เหมือนเดิม แต่เอา **รูปครบทุกใบ** ไม่ใช่ใบแรกใบเดียว

**ไฟล์ที่ได้ออกมา**

```
_r2_upload/
  gallery/<Product ID>/01.jpg 02.jpg …     ← 1024px q82  (เรียงตามเลข (N) ในชื่อไฟล์เดิม)
  gallery/thumb/<Product ID>.jpg           ← 256px  q78
  index/gallery.json                       ← manifest
  qc_missing_photo.csv                     ← Instock ที่ไม่มีรูปเลย (คาดว่า 26 แถว)
  qc_orphan_folder.csv                     ← โฟลเดอร์ที่ไม่มีในชีต (คาดว่า 14 แถว)
  qc_matched_by_fallback.csv               ← ที่จับคู่ด้วยชั้น B/C — ให้ตาคนตรวจซ้ำ
  qc_summary.txt                           ← ตัวเลขสรุปรอบนี้ เทียบรอบก่อนได้
```

- `--resume` เป็นค่าเริ่มต้น (ข้ามไฟล์ที่ย่อแล้ว) เหมือนของเดิม → รันซ้ำถูกและเร็ว
- `--limit N` ไว้ลองก่อน · `--dry-run` = ออกแต่ `qc_*.csv` ไม่ย่อรูป
- **ไม่แตะไฟล์ต้นฉบับใน `All Products/` เด็ดขาด**

**หน้าตา `gallery.json`**

```json
{
  "version": "2026-08-15T14:30:00+07:00",
  "base": "https://pub-366b23912e6144bc8240fcf7e6764d01.r2.dev/gallery/",
  "items": {
    "OWA-GGBF027YKAR01": {
      "n": 4,
      "src": "Final Fantasy XIII (RESTOCK-01)",
      "match": "exact",
      "files": ["Final Fantasy XIII (RESTOCK-01) (1).jpg", "… (2).jpg", "… (3).jpg", "… (4).jpg"]
    }
  }
}
```

- URL รูปที่ i = `base + PID + "/" + zeroPad(i+1) + ".jpg"` → ฝั่งเว็บคำนวณเองได้ ไม่ต้องเก็บ URL เต็ม
- `files` เก็บ**ชื่อเดิม** ไว้ตั้งชื่อไฟล์ตอนดาวน์โหลด/ใส่ zip
- `match` (`exact` / `base` / `override`) ไว้ให้ UI ขึ้นธงเตือนเล่มที่จับคู่แบบเดา
- ขนาดไฟล์คาดการณ์ ~**60 KB** สำหรับ 439 เล่ม → โหลดครั้งเดียวตอนเปิดแอป ไม่กระทบ

### I2 — R2: อัปโหลด + CORS

**เปิด CORS (จำเป็น — ไม่มีอันนี้ ปุ่มดาวน์โหลดกับ zip ทำงานไม่ได้)**

Cloudflare Dashboard → R2 → `owarin-images` → Settings → **CORS Policy** → วาง:

```json
[
  {
    "AllowedOrigins": ["*"],
    "AllowedMethods": ["GET", "HEAD"],
    "AllowedHeaders": ["*"],
    "ExposeHeaders": ["Content-Length", "Content-Type"],
    "MaxAgeSeconds": 86400
  }
]
```

> ทำไม `*` — เว็บแอป Apps Script รันในโดเมน `https://n-xxxxxxxx-....googleusercontent.com`
> ที่ **สุ่มใหม่ทุก deployment** จึงระบุ origin ตายตัวไม่ได้ · bucket นี้เป็น public อยู่แล้ว ไม่ได้เปิดอะไรเพิ่ม

**คำสั่งอัป**

```powershell
cd "C:\Users\JIN\OneDrive\Desktop\etc\OWARIN\OWARIN STORE\_r2_upload"
rclone copy gallery r2:owarin-images/gallery --progress --transfers=8
rclone copy index   r2:owarin-images/index   --progress
rclone size r2:owarin-images
```

**ทดสอบก่อนไป I3** (3 ข้อ ต้องผ่านหมด)

1. เปิด `https://pub-….r2.dev/gallery/OWA-GGBF027YKAR01/01.jpg` ในมือถือ → เห็นรูป
2. เปิด `https://pub-….r2.dev/index/gallery.json` → เห็น JSON
3. เปิด Console เบราว์เซอร์ที่หน้าเว็บอะไรก็ได้ แล้วรัน
   `fetch('https://pub-….r2.dev/gallery/OWA-GGBF027YKAR01/01.jpg').then(r=>r.blob()).then(b=>console.log(b.size))`
   → ได้ตัวเลข = CORS ผ่าน · ขึ้น `CORS error` = ยังไม่ผ่าน กลับไปแก้ policy

### I3 — `Index.html` + `WebApp.gs`

**เพิ่มใน `WebApp.gs`** — action เดียว:
`getImageBase()` → คืน `{base, manifestUrl}` อ่านจาก `R2_PUBLIC_URL` ที่ `Code.gs` มีอยู่แล้ว
(ทำแบบนี้เพื่อให้ย้ายไป custom domain ทีหลัง = แก้ `Code.gs` บรรทัดเดียว ไม่ต้องแตะ HTML)

**เพิ่มใน `Index.html`**

| จุด | สเปก |
|---|---|
| โหลด manifest | `fetch(manifestUrl)` **ครั้งเดียว** พร้อม inventory index ตอนเปิดแอป · ล้มเหลว → แอปยังทำงานปกติ แค่ไม่มีรูป (graceful degrade) |
| แถวใน list | thumbnail **48×64** ชิดซ้าย · `loading="lazy"` · `decoding="async"` · badge เลข `×4` มุมขวาล่างถ้ามีมากกว่า 1 ใบ |
| ไม่มีรูป | กรอบเทา ไอคอน 📷 จาง — **ไม่ใช่ภาพแตก** |
| จับคู่แบบ fallback | ขอบซ้ายสีทองบาง ๆ + tooltip "จับคู่จากชื่อฐาน — ตรวจสอบ" |
| หน้ารายละเอียด | แถบรูปเลื่อนแนวนอน (ทุกใบ) → แตะเปิด **lightbox**: ปัดซ้าย/ขวา · ปุ่ม `‹ ›` · `Esc`/แตะพื้นหลังปิด · ตัวนับ `2 / 4` |
| ฟิลเตอร์ใหม่ | `รูป: ทั้งหมด / มีรูป / ไม่มีรูป` — **แทนที่การต้องเปิด `pocketbook_need_photo.csv`** |
| ดีไซน์ | ตาม design tokens §2.1 ของแผน v4.1 — พื้น `hsl(0 0% 5%)` · ขอบ `hsl(0 0% 18%)` · **radius 0** · ไม่มีเงา |

**เรื่องความเร็ว (สำคัญ)**
list 465 แถว × รูปเต็ม 150 KB = **70 MB** → มือถือตายแน่
→ นี่คือเหตุผลที่ต้องมี `gallery/thumb/` 256px (~15 KB) แยก: **465 × 15 KB ≈ 7 MB** และ `loading="lazy"` ทำให้โหลดจริงแค่ที่เห็นบนจอ (~10 รูป ≈ 150 KB)
รูปเต็มโหลดเฉพาะตอนเปิด lightbox เท่านั้น

### I4 — Copy & Download

**ความจริงเรื่องข้อจำกัด — อ่านก่อน**

| สิ่งที่อยากได้ | ทำได้ใน iframe ของ Apps Script? | ทางออก |
|---|---|---|
| Copy **ลิงก์ทั้งชุด** เป็นข้อความหลายบรรทัด | ✅ ได้แน่นอน | `navigator.clipboard.writeText` + `execCommand('copy')` fallback — **แพตเทิร์นที่ P1 ใช้อยู่แล้ว** |
| Copy **ไฟล์รูป** ลง clipboard | ⚠️ ไม่รับประกัน | เบราว์เซอร์ยอมให้วางได้ **ทีละ 1 รูป และต้องเป็น PNG** เท่านั้น · iframe ข้ามโดเมนมักโดน Permissions-Policy บล็อก และ Apps Script ตั้ง `allow="clipboard-write"` ให้ไม่ได้ · Safari/iOS เข้มกว่านั้นอีก |
| ดาวน์โหลดทีละใบ | ✅ ได้ | `<a download>` **ใช้ไม่ได้กับไฟล์ข้ามโดเมน** → ต้อง `fetch → blob → createObjectURL → a.download` (**ต้องมี CORS จาก I2**) |
| ดาวน์โหลด **ทั้งชุดเป็น zip** | ✅ ได้ | JSZip จาก cdnjs (allowlist อนุญาต) · ตั้งชื่อ `<ชื่อเล่ม>.zip` · ข้างในใช้ชื่อไฟล์เดิมจาก manifest |

**สรุปเป็น 3 ปุ่มในหน้ารายละเอียด**

```
📋 Copy ลิงก์ทั้งชุด     → คัดลอกข้อความ:
                            Final Fantasy XIII (RESTOCK-01)
                            https://pub-….r2.dev/gallery/OWA-…/01.jpg
                            https://pub-….r2.dev/gallery/OWA-…/02.jpg
                            …
                            (แปะในแชท FB/LINE ลูกค้ากดดูได้เลย ทำงานทุกเบราว์เซอร์)

⬇️ โหลดทั้งชุด (.zip)    → 4 รูป · ชื่อไฟล์เดิม · ~600 KB
                            (แถบความคืบหน้าระหว่างดึงทีละไฟล์)

🖼️ เปิดหน้าคลังรูป        → window.open หน้า top-level เล็ก ๆ
                            → ที่นั่นถึงจะมีปุ่ม "Copy รูปนี้" (image/png ลง clipboard)
                              เพราะหลุดจาก iframe sandbox แล้ว
                            → และคลิกขวา → Copy image ก็ทำได้ตามปกติ
```

> **ข้อเสนอเชิงปฏิบัติ:** ถ้าปลายทางคือแปะในแชทให้ลูกค้าดู — **"Copy ลิงก์ทั้งชุด" ดีกว่าการ copy ไฟล์รูป** เพราะได้รูปครบทุกใบในครั้งเดียว ไม่ต้องวนแปะทีละใบ และไม่มีข้อจำกัดเบราว์เซอร์เลย ส่วนการ copy ไฟล์จริงเก็บไว้ที่หน้าคลังรูป (top-level) สำหรับตอนที่ต้องแนบไฟล์จริง ๆ

**ปุ่มรวมในโหมดเลือกหลายเล่ม** (ต่อยอด bulk select ที่ P2 วางไว้): เลือก 5 เล่ม → `📋 Copy ลิงก์ทุกเล่ม` ได้ข้อความแยกบล็อกต่อเล่ม — ใช้กับโพสต์ NEW ARRIVAL ได้ทันที

## 6. ความเสี่ยงและข้อจำกัดที่ต้องรู้

| ความเสี่ยง | ผลกระทบ | วิธีรับมือ |

| **`r2.dev` มีลิมิตการเรียก** | รูปโหลดช้า/ไม่ขึ้น ถ้าลูกค้าเข้าเยอะ | ตอนนี้ใช้ภายในร้าน ยังพอ · ถ้าเริ่มช้า → ผูก custom domain (ฟรี) แล้วแก้ `R2_PUBLIC_URL` ใน `Code.gs` **บรรทัดเดียว** ลิงก์เก่าไม่พัง |
