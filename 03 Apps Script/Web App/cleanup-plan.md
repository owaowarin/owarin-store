## ส่วนที่ 1 — เมนู Inventory Tools (Code.gs)

**ตอนนี้:** 3,685 บรรทัด · 108 ฟังก์ชัน · **29 รายการเมนู**

ปัญหาไม่ใช่โค้ดตายเยอะ (มีแค่ 2 ฟังก์ชันที่ไม่มีใครเรียก) แต่เป็น**เมนูรก** เพราะเครื่องมือย้ายข้อมูลครั้งเดียวยังปนอยู่กับเครื่องมือใช้ประจำ

### แบ่งกลุ่มตามการใช้งานจริง

**A. ใช้ประจำทุกวัน — ต้องอยู่หน้าสุด (8 รายการ)**

| เมนู | ใช้ตอนไหน |
|---|---|
| 💰 คำนวณราคา SP-2 | ของเข้าใหม่ / ทบทวนราคา |
| 👀 พรีวิว: เอาราคา SP-2 ไปใส่ Price | ก่อนใช้ราคาจริง |
| ✍️ ใช้ราคา SP-2 | ยืนยันราคา |
| 🚨 Audit ราคาต่ำกว่าตลาด | เช็กของที่ตั้งถูกเกิน |
| 🔶 Review Queue ของหายาก | ของ R1 ที่ต้องเคาะเอง |
| ✅ ตรวจสอบ Product ID | หลังเพิ่มของ |
| 🔤 เรียงลำดับ A-Z | จัดชีตให้อ่านง่าย |
| 🧮 เติมสูตร Market·Profit·Content | เมื่อสูตรหาย |

**B. Facebook Catalogue — รวมเป็นเมนูย่อยชุดเดียว (4 รายการ)**

`📘 จัด FB CATALOGUE` → `✍️ สร้าง Description ใหม่` → `📤 META EXPORT` + `🔽 ตรวจ dropdown`

ทั้งสามตัวแรกต้องกด**ตามลำดับ** — ควรอยู่ในเมนูย่อยชื่อ "📘 Facebook Catalogue" พร้อมเลข 1/2/3 กำกับ จะได้ไม่กดสลับ

**C. ดูแลข้อมูลนาน ๆ ครั้ง — ย้ายเข้าเมนูย่อย (4 รายการ)**

🏷️ เติม Copy Flags · 💎 เติม Rarity · 🔍 หา Sold ที่น่าจะเป็น Auction · 🔍 ตรวจ Publisher ไม่มี Code

**D. ตั้งค่าครั้งเดียว — ย้ายเข้าเมนูย่อย (3 รายการ)**

🧱 SP-2 Setup · 🎨 จัดหน้าชีต · ⚙️ ติดตั้ง Trigger

**E. อันตราย — เก็บในเมนูย่อยพร้อมคำเตือน (2 รายการ)**

🛠️ จัดระเบียบเลข RESTOCK ⚠️ · 🔄 สร้าง SKU ใหม่ทั้งหมด ⚠️ · ✍️ ใช้ราคาแบบทับทุกกรณี

**F. งานย้ายข้อมูลที่ทำเสร็จแล้ว — เสนอให้ถอดออกจากเมนู (7 รายการ)**

| เมนู | ทำอะไร | สถานะ |
|---|---|---|
| 🗂️ สร้าง/อัปเดตตารางซีรีส์ (SERIES MAP) | สร้างชีต SERIES MAP | ชีตถูกลบไปแล้ว |
| 🧭 จัดโครงสร้างชีตตามแผน | เปลี่ยนชื่อชีต 10→7 | ทำเสร็จแล้ว |
| 🏷️ เพิ่มคอลัมน์ Type | สร้างคอลัมน์ Type | ทำเสร็จแล้ว |
| 🔗 เติม Series ใน GAME INFO | เติม Series | ยังไม่ได้ใช้ (คอลัมน์ยังว่าง) |
| 📚 กรอก Platform/Genre กลุ่ม GAMEMAG SPECIAL | เติมหมวดนิตยสาร | ทำเสร็จแล้ว |
| 🎮 กรอก Genre ที่ตรวจจากปกแล้ว | เติม Game Online ฯลฯ | ทำเสร็จแล้ว |
| 🧹 จัดระเบียบ Genre 55→24 | ยุบ genre | ทำเสร็จแล้ว |

> **ไม่ลบโค้ด แค่ถอดออกจากเมนู** — ฟังก์ชันยังอยู่ เรียกใช้จาก Apps Script editor ได้ถ้าต้องใช้อีก
> เผื่อวันหน้าทำนิตยสารต่อ จะได้ไม่ต้องเขียนใหม่

### 2.4 โฟลเดอร์รูป — ต้องให้คุณตัดสินใจ

| โฟลเดอร์ | เนื้อหา | คำถาม |
|---|---|---|
| `GGB All/` | รูปสินค้าหลัก 4 หมวด | **ตัวจริง เก็บ** |
| `Magazine/` · `Magazine - Gundam/` | รูปนิตยสาร | เก็บ (จะทำแค็ตตาล็อกทีหลัง) |
| `Products/` | 732 ไฟล์ 1.9 GB ขนาดใหญ่ | ต้นฉบับความละเอียดสูง? ซ้ำกับ GGB All ไหม |
| `Main Post New/` (158) | รูปโพสต์ | ซ้ำกับ GGB All ไหม |
| `NA - GGB/` (23) · `New Arrival List/` (51) | รูปของเข้าใหม่ | ของเก่าที่ลงไปแล้วหรือยัง |
| `SOLD OUT/` (84) | รูปของที่ขายแล้ว | ยังต้องใช้ไหม |
| `GGB Online Files/` (21) | ไฟล์ PDF คู่มือ | คนละเรื่องกับรูปสินค้า |
| `Supplier/` (5 โฟลเดอร์) | แยกตามซัพพลายเออร์ | ใช้อยู่ไหม |
| `Facebook - Group/` (4 txt) | ข้อความโพสต์ | ย้ายเข้าชีต TEMPLATES ได้ไหม |

**ข้อสังเกต:** `Products/` ใหญ่ที่สุด (1.9 GB) แต่ `GGB All/` (789 MB) คือตัวที่สคริปต์ใช้จริง ถ้า `Products/` เป็นต้นฉบับก่อนตัดแต่ง ควรย้ายออกไปไดรฟ์สำรองแทนที่จะเก็บใน OneDrive

## ลำดับที่แนะนำ

1. **ลบ `r2-setup.bat` ก่อนเลย** (มีรหัสลับ) — ทำได้ทันที ไม่ต้องรออะไร
2. จัดเมนู Apps Script (ส่วนที่ 1) — ผมแก้ Code.gs ให้ได้ ไม่กระทบข้อมูล
3. ย้ายเอกสารเก่าเข้า `_archive/`
4. ตอบคำถามเรื่องโฟลเดอร์รูป (2.4) แล้วค่อยจัดโครงสร้างใหญ่

> ⚠️ ข้อ 4 กระทบสคริปต์ — `prepare_r2_upload.py` อ้างชื่อโฟลเดอร์ `GGB All/GGB - POCKET BOOK` ตรง ๆ
> ถ้าย้ายโฟลเดอร์ต้องแก้ค่า `IMAGE_ROOTS` และ `SOURCE_DIR` ในสคริปต์ด้วย
