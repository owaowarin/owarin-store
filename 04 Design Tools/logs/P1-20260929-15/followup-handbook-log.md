

### P1-15 handbook correction for unresolved Add responses (2026-09-29)

The target Error handbook wording could be read as if a timeout immediately exposes a retry button. Current **test** Index uses `sessionStorage` per tab; while an Add callback never returns, the form stays Saving, with no application watchdog. DONE returns the existing item; NOT_FOUND resends the same ID; PREPARED/ERROR/unclear states retain the draft for reconciliation. A new tab/device without that session state has no automatic Request ID recovery and must not blindly create a new ID.
